院系领导

^^^

这笔采购院系能否自主拍板，是否必须走校级招投标

本产品定位为教学辅助工具软件，一口价含税总价为 ￥13,555 元，金额适配院系自主采购权限，院系可自主立项采购，无需上级招投标审批流程，立项与经费决策可在院系内部完成。产品参数无排他性，符合政府采购公平公开要求，采购流程合规透明，便于院系快速决策、快速落地。实际是否由院系自主采购与院校采购政策有关，请依据院校实际采购政策进行决策。

^^^

一次付款后，后续是否还会产生年费、节点费、云算力费等隐性支出

本产品一次采购即授予永久使用授权，长期开课无年费、无节点费。软件纯 CPU 离线运行，无需 GPU 服务器、亦无需 GPU 云资源，因此不产生任何持续算力费用。首年提供免费基础技术服务；后续年度服务明码标价、按需选购、不捆绑消费，院系可完全掌控支出节奏，不存在被持续绑定付费的风险。

^^^

软件涉及开源框架与人脸等实训数据，知识产权与数据安全责任如何界定

软件供应商向院系作出六项合规承诺：产品为自主研发、权属清晰，如出现侵权由软件供应商全权承担责任；严格遵守 OpenCV、PyTorch、ONNX、OpenVINO 等开源协议，可提供开源清单与合规说明；软件不含木马、后门、挖矿、病毒等有害代码；全流程本地 CPU 离线运行，不上传任何图像、视频、模型与实训数据，数据完全由校方掌控；不采集、不上传、不泄露师生个人信息，人脸、姿态、手势类实训数据仅本地临时使用，符合教育行业隐私合规要求。院系可据此规避版权与隐私合规风险。

若出现合同纠纷或产品事故，院校资金风险有多大

销售政策明确约定，因软件供应商原因产生的违约金、赔偿金等，全部累计上限不超过合同实际成交金额，院校赔偿责任封顶、资金风险可控、责任边界清晰。软件供应商按国家规定开具正规发票，财务流程合法合规，满足院校入账、审计与各项检查要求，院系在资金与财务环节无后顾之忧。

实训领导

^^^

我院机房设备老旧、没有 GPU，能否承载计算机视觉实训

本产品纯 CPU 离线运行，软硬件要求仅为 Windows 10/11、CPU i3 及以上、内存 ≥4G，可直接部署于普通计算机机房，无需采购昂贵的 GPU 设备、亦无需租用 GPU 云服务器。这使院校能够盘活存量老旧机房硬件资产，让原本难以承担 AI 实训任务的老旧电脑直接投入视觉实训教学。推荐院系使用本软件在机房计算机设备上进行实际测试，以确定本产品是否能在机房软硬件上正常运行。

^^^

一个班级几十名学生上机，授权并发是否受限

本产品无并发授权限制，一个班级全部学生可运行实训程序，天然适配整班上机、集中实训周、课程设计与技能训练等排课场景，实训组织不受授权点数制约。一个院系一次采购最多可部署4个机房，每一个机房可部署30到100台学生计算机设备。

^^^

部署是否需要逐台安装 Python 环境，落地周期多长

每个实践均为独立的Windows 10 X64版本的可执行程序（.exe），免安装 Python 依赖软件包，师生无需自行安装开发环境。70个实践程序（总共约40GB空间）完整拷贝到机房学生计算机上，在学生计算机上设定机房局域网上部署的License授权服务器IP和端口的系统变量，即可完成批量部署。如果学生计算机硬盘空余空间有限，可在每次实践时根据该次实践需求拷贝指定实践程序。确保在标准机房离线稳定运行，最快一周内即可在现有普通机房落地整套实训体系，部署与运维成本低。

^^^

机房操作系统权限不一、机器软硬件条件存在差异，出现运行故障如何保障

在标准Windows 10 X64系统下软件可离线稳定运行；考虑到机房操作系统权限、设备配置差异可能引发偶发运行故障，首年提供免费技术服务，含 4 个 BUG 修复、总工时 200 小时以内，并提供远程协助。需要说明的是，标准授权不含上门服务、版本升级与非约定故障修复，超出首年范围的工作可按后续年度按需服务明码结算、不捆绑消费。

^^^

验收与资产入库时，软件供应商交付物清单是否完整

标准交付物包括：课程实践管理信息系统软件、软件实践程序、操作手册、安装手册、License服务器软件、以及授权License。院系可对照清单逐项验收、登记资产台账，交付边界清晰，便于资产入库与后续审计。BUTIANYUN.COM提供获取数据集、预训练模型、测试图片、测试视频、教学案例的有效途径，教师可在教学实践活动中合法使用这些数据。这些数据不是标准交付物的组成部分。

^^^

后续若需调整案例或新增功能，费用与流程如何约定

后续年度服务明码标价、不捆绑：单价 100 元/工时，每年最多 10 个任务（BUG 修复或功能新增二选一），单个任务不超过 60 小时（约 7 个工作日）；流程为软件供应商先估算工时、按估算值结算、超时不增收费用，复杂任务可拆分后双方协商执行。首年免费服务不含新增功能与版本升级，院系可根据实际需要灵活选购，避免为不需要的服务付费。

CV 教研专家

^^^

实践内容能否覆盖从基础到部署的完整技术链路

本产品按“图像处理 → 图像分类 → 目标检测 → 图像分割 → 姿态检测 → 面部识别 → 目标跟踪 → 手势识别 → 可视化 → 数据标注 → 数据增强 → 数据处理 → 网络训练 → 模型部署”组织 14 大技术主题、70 个应用实践。每个实践均为独立可执行程序，并配套 PDF 操作手册，覆盖安装与使用全过程，可支撑一门课程从入门认知到工程部署的完整教学链路，避免教学内容碎片化。

^^^

所采用的技术框架是否与工业界主流一致，学生能否对接岗位需求

实践基于 OpenCV、PyTorch、YOLO 等业界主流开源框架实现；模型部署环节覆盖 ONNX 与 OpenVINO 两条工程化路径，并分别提供 Python 与 C++ 版本，完整呈现模型转换与跨语言部署过程。教学流程对齐工业界真实开发与部署流程，有助于缩小院校教学与企业岗位需求之间的差距，使学生掌握的工具链与企业实际一致。

^^^

纯 CPU 环境能否支撑模型训练环节，教学链路会不会在“训练”中断裂

本产品内置目标检测验证、训练、测试、恢复训练与预测等全套网络训练实践，可在 CPU 环境完整复现“训练—迭代—评估”流程，满足大中专层次教学示范与轻量化训练需求。需要客观说明的是：纯 CPU 环境降低了硬件成本，但无法支撑超大规模数据集的完整训练、训练耗时较长，不适合大型模型训练实验；高阶大模型与大规模并行训练仍建议院校另行搭配 GPU 集群使用。本产品定位于经济实用型实训，而非科研级训练平台。 本产品提供了数据集抽取软件程序，可从业界常见的大规模数据集中抽取出适合普通机房CPU训练的数据集。

^^^

软件多为图形化封装程序，学生是否只会点击按钮、学不到算法原理

本产品兼顾两种学习模式：图形化 GUI 版本供零基础学生零代码快速上手，提供 From-Scratch 手写实现版与 Console 代码版本，供基础较好的学生深入代码层。软件还内置热力图、CAM 卷积网络结构可视化、模型网络结构可视化等模块，直观破解深度学习“黑盒”。需要教研侧配合的是，软件不会自动强制学生修改参数调试，建议采用“软件实操 + 手写代码”相结合的教学设计，布置手写核心代码、参数修改对比类作业，确保原理真正落地。BUTIANYUN.COM根据本产品14大技术主题涉及的技术原理，整理了对应的技术原理参考手册，可供学生课外阅读拓展知识面。BUTIANYUN.COM设立了微信公众号，发表了400+篇计算机视觉领域的技术博客，可供学生进一步掌握计算机视觉高阶技术原理。

V1.0 案例与模型固定，后续行业出现新模型、新业务方向时课程如何更新

V1.0 版本的软件功能固定，新增功能需与软件供应商商榷解决。 本产品打造了具有自主知识产权的计算机视觉实训完整工具链，包括数据标注软件、数据增强软件、数据处理软件、网络训练软件、模型测试验证软件、可视化软件、模型部署软件。 教师完全能补充新的行业数据集、测试图片、测试视频，使用本产品训练出新的行业模型，应用新的模型和测试数据设计新的行业教学案例。软件采用模块化架构，各实践程序相互独立，便于后续版本迭代时更新模块内容。若院系确有新增功能需求，可在后续年度按软件供应商明码标价的按需服务提出：单价 100 元/工时，每年最多 10 个任务（BUG 修复或功能新增二选一），单个任务不超过 60 小时，先估算工时、按估算值结算、超时不增收，复杂任务可拆分后双方协商解决。

CV 实践课教师

^^^

备课是否需要从零搜集代码、数据集与案例

本产品每个实践均配套 PDF 操作手册，覆盖安装与使用全过程，并内置数据集、预训练模型、测试图片与测试视频，教师可复用现成模块直接开展教学，依托操作手册快速生成教案，无需从零搜集代码、数据集与案例。例如：用全景图拼接做 OpenCV 入门，用水果目标检测讲解检测任务，用 CAM 可视化解析深度学习原理，用数据标注与模型转换模块构建模型部署章节。

^^^

学生基础差异大，软件能否支持分层教学

软件提供分层实践素材：基础薄弱的学生可使用 GUI 图形化版本零代码完成实验，能力较强的学生可使用 From-Scratch、Console 代码版本深入代码层，便于教师在同一课堂内实施分层教学。需要说明的是，软件仅提供分层实践素材，具体的分层任务编排、作业要求与学习指引，仍需教师结合课程进度自行设计完善。

^^^

深度学习原理抽象、模型“黑盒”，课堂上如何向学生讲清内部机制

软件内置热力图可视化、CAM 卷积网络结构可视化、模型网络结构可视化（YOLO / PyTorch / ONNX 三种视角）、模型数据产生器与预训练模型获取等模块，可直观展示网络内部逻辑；并配套完整的训练—验证—测试—恢复训练工具链，完整复现训练、迭代、评估流程。建议教师在此基础上额外设计调参、排错类任务，引导学生主动思考底层逻辑，避免停留在“看结果”层面。

如何避免学生“跑通了程序却不懂原理”

建议采用“软件实操 + 手写代码”相结合的教学设计：先由学生通过软件完成实验现象观察，再布置手写核心代码、参数修改对比类作业；基础操作类答疑由操作手册承接，教师将精力集中于原理讲解与调参指导，并可自行整理高频报错库以减轻答疑压力。应合理规划实验规模，优先选用轻量化训练任务，规避 CPU 算力短板，使课堂节奏可控。 BUTIANYUN.COM根据本产品14大技术主题涉及的技术原理，整理了对应的技术原理参考手册，可供学生课外阅读拓展知识面。BUTIANYUN.COM设立了微信公众号，发表了400+篇计算机视觉领域的技术博客，可供学生进一步掌握计算机视觉高阶技术原理。
