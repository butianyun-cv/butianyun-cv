补天云火鸟视频创作软件

生成PDF · 生成博客 · 生成音视频 · 自动配音 + 自动配字幕

补天云火鸟视频创作软件是一款操作手册创作工具，包括：音频操作手册、视频操作手册、博客操作手册、PDF操作手册、动画操作手册，自动配音与自动配字幕功能， 提升创作效率。视频 + 图片 + 文本批量生成 MP4、文本批量生成 MP3、视频 + 图片 + 文本批量生成 PDF / HTML、视频批量生成 GIF 动画。

核心特点

  • 批量生成
  • 自动配音
  • 自动配字幕
  • 批量生成：一天可轻松创建多达 100 个视频。
  • 自动配音：基于系统 TTS 引擎（Windows 10 默认提供 WinRT 和 SAPI 两种）。
  • 自动配字幕：基于 TTS 引擎输出自动生成字幕。

核心功能

功能 格式 说明
视频生成 MP4 视频 + 图片 + 文本批量合成
音频生成 MP3 文本批量转换为音频
操作手册生成 PDF / HTML 视频 + 图片 + 文字批量生成
动画生成 GIF 视频批量转换为 GIF 动画

适用领域

  • 课程创作
  • 视频创作
  • 音频创作
  • PDF 电子书创作
  • 博客专栏创作

目录结构

软件采用三级目录结构组织素材：

源总目录
└── 章目录
    └── 节目录
        └── 小节目录（含图片、文本、标题素材）
  • 图片格式：支持 JPG、PNG、TIF。
  • 文本编码：必须为 UTF-8。
  • 多语言支持：通过文件命名标记（如 title_zh.txt、image_en.txt）实现中、英、日、俄等多语言版本。

系统依赖

  1. TTS 引擎（文本转语音）：Windows 10 默认提供 WinRT 和 SAPI 两种，需安装对应语言包。
  2. 麦克风录音功能：需在系统隐私设置中启用。
  3. 混音设备：Windows 系统需启用立体声混音，用于录制系统声音。
  4. VC 可再发行运行时库：首次运行需安装 vc_redist.x64.exe。

软件参数

通用选项

工作目录（输出文件路径）、FFMPEG 可执行文件路径、界面语言。

作者选项

作者信息、水印信息、LOGO 图片。

TTS 选项

TTS 引擎与语言选择、语音角色（男声 / 女声等）、音频录音设备。
