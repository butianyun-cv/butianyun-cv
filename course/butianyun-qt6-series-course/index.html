补天云 QT6 系列课程

QT6 编程入门 · QT6 界面美化 · QT6 性能优化 · QT6 网络编程

补天云 QT6 系列课程围绕 QT6 框架展开，覆盖 QT6 编程入门、QT6 界面美化、QT6 性能优化、QML 性能优化、QT6 网络编程、QT6 QML 在增强现实中的应用等方向。 帮助学习者掌握 QT6 相对 QT5 的演进、新的 API 与模块特性，并结合实际项目理解最佳实践。

本系列课程包含的课程

1. QT6 编程入门

QT6 环境搭建与安装：安装 QT6、MinGW 或其他 C++ 编译器、IDE 集成开发环境、必要软件库与工具。Qt Quick 编程、事件处理、网络编程、数据库操作等基础知识。

2. QT6 界面美化

基于 QT6 的界面美化方法，结合 QSS 与 QML 改进界面观感与交互体验。

3. QT6 性能优化

QT6 应用性能优化方法，覆盖渲染、内存、启动等关键环节。

4. QML 性能优化

QML 性能优化专项：QML 编译缓存（qtquickcompiler）、纹理压缩、视图回收机制（Repeater 与 ListView 优化）、C++ 后端数据模型高效封装等。

5. QT6 网络编程

QT6 网络模块详解：QNetworkAccessManager、QTcpServer、QTcpSocket 等网络类。套接字编程基础（QAbstractSocket 子类、客户端/服务器通信）、变长数据包收发等实战内容。

6. QT6 QML 在增强现实中的应用

QT6 QML 框架简介与在增强现实场景中的应用方法。
