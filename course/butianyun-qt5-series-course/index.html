补天云 QT5 系列课程

QT5 原理与源码 · QML C++ 高级扩展 · QT 界面美化 · QT 网络编程

补天云 QT5 系列课程围绕 QT5 框架展开，覆盖 QT5 原理与源码分析、QML 与 C++ 高级扩展开发、QT 界面美化（QSS 与 QML）、QT 网络编程、Qt Quick 网络动画 / 粒子系统 / 图形特效等方向。 帮助学习者系统掌握 QT5 的核心机制与典型应用场景。

本系列课程包含的课程

1. QT5 原理与源码分析视频课程

从底层机制讲解 QT5 框架：元对象系统（moc 预处理器、运行时类型信息、信号与槽机制、属性系统）、事件循环（事件队列、事件派发器、事件过滤器）、内存管理（对象树父子关系、QByteArray 隐式共享与写时复制）、多线程与并发（QThread 两种范式、Worker + moveToThread、QThreadPool + QRunnable）、图形绘制（QPainter 状态机、QGraphicsView 空间索引、OpenGL 集成）、网络通信（QNetworkAccessManager、Socket 编程、粘包拆包、心跳保活、断线重连）。

2. QT5 QML C++ 高级扩展开发视频课程

QML 与 C++ 的高级集成：QML 与 C++ 交互、QML 扩展开发、C++ 模块封装、高阶界面开发。覆盖信号与槽跨语言通信、C++ 类注册到 QML、QML 调用 C++ 方法、界面与业务逻辑分离等内容。

3. QT 界面开发（QT5 QML + QT Quick 网络动画、粒子系统、图形特效）

基于 QML 与 Qt Quick 的界面开发：网络动画、粒子系统、图形特效等高阶应用。适合需要构建动态、视觉效果丰富的桌面应用的开发者。

4. QT5 QML 界面美化详解视频课程

Qt Quick 界面美化：组件样式定制、动画效果实现、主题切换、细节优化等内容。覆盖颜色、字体、边框、圆角等属性的精细化调节方法。

5. 电脑管家软件界面美化项目实战视频课程（QT5 QSS）

通过完整项目（电脑管家软件）实战 QT5 QSS 界面美化方法，掌握 QSS 样式表的实际应用。

6. C/C++ QT 公开课

QT 基础公开课内容，作为 QT5 系列课程的入门补充。

7. C/C++ QT 公开课第一季（QT5 界面美化 QSS、QML、C++11、STL）

第一季公开课内容，覆盖 QT5 界面美化（QSS、QML）、C++11 与 STL 等知识。
