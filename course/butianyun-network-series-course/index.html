补天云 网络系列课程

常用 Web 技术 · 网络通讯协议 · 桌面应用网络编程

补天云网络系列课程介绍几种常用 Web 技术与网络通讯协议，并结合 QT 框架的网络模块讲解桌面应用中的网络编程方法。 帮助开发者掌握 HTTP、TCP / UDP、Socket 等常见网络通信能力，以及 QT 网络模块（QNetworkAccessManager、QTcpServer、QTcpSocket 等）的实际使用。

本系列课程主要内容

常用 Web 技术

围绕桌面应用与 Web 集成的常用 Web 技术展开，包括 Web 资源请求、HTML / JavaScript 集成、混合应用开发等基础内容。

常用网络通讯协议

讲解常见网络通讯协议（HTTP、TCP、UDP）的概念与典型应用场景，理解请求/响应模型、连接管理、数据分包等关键概念。

QT 网络编程

基于 QT 框架的网络模块讲解：QNetworkAccessManager、QNetworkRequest 等高层 API；QTcpServer / QTcpSocket 套接字编程；变长数据包收发（用户注册 / 用户登录示例）；粘包拆包、心跳保活、断线重连等实战经验。

QT 与 Web 通信

结合 QT 应用场景，讲解 Web 应用开发要点、QT WebEngine 使用等。
